# 游戏内DNS解析器与缓存系统

## 项目描述

游戏内DNS解析器与缓存系统的bug修复项目。核心模块 `network/dns_resolver.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 查询解析完全没做不能解析DNS查询报文
- 递归查询完全没做只能查根服务器
- 缓存完全没做每次都重新查询
- 记录解析完全没做不能解析DNS记录
- DNS安全完全没做容易被DNS欺骗

## 运行测试

```bash
python -m pytest tests/test_dns_resolver.py -q
```

修复目标：所有 13 个测试全部通过。

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
